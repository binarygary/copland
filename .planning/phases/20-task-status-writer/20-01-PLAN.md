    Create the file `app/Services/TaskDirectoryWriterService.php` in namespace `App\Services` per D-12. Import `App\Support\HomeDirectory` and `RuntimeException`.

    Implements TASK-01 (writeNewTask, per D-08 "task.md is written ONCE on creation") and TASK-02 (writeStatus rewrites frontmatter + appends transitions row on every call; writeBlockedIfNotTerminal is the crash-recovery entry per D-11).

    Class shape and conventions (per CLAUDE.md, PATTERNS.md Pattern 1-2):
    - PascalCase service class name; the file is the canonical home for the writer.
    - Constructor uses property promotion with two optional trailing nullable seams: `private $clock = null` (callable) and `private ?string $homeOverride = null`. Mirrors `GitService::__construct(private $runner = null)` per D-13.
    - Private property `private array $lastState = []` keyed by `"{repoSlug}/{taskId}"` (string) — in-memory only, never persisted. Used by writeBlockedIfNotTerminal.

    Public method `writeNewTask(string $repoSlug, string|int $taskId, ?string $title, ?string $body, string $repoPath, ?string $sourceUrl): void`:
    - Resolve $dir via `taskDir($repoSlug, $taskId)` (private helper, see below).
    - Call `ensureDirectoryExists($dir)`.
    - Build frontmatter pairs in this exact order: id, title, repo_slug, repo_path, source_url, created_at. Cast id to string. Coerce nullable title/sourceUrl to "" via `(string) ($x ?? '')`. created_at comes from `now()`.
    - Render frontmatter via `renderFrontmatter()` (hand-rolled per Don't-Hand-Roll guidance — DO NOT use symfony/yaml). Wrap with explicit `---\n` and `---\n` delimiters per RESEARCH Pitfall 4.
    - Compose final content: `"---\n{$rendered}---\n\n" . (string)($body ?? '') . "\n"`.
    - Write atomically via `atomicWrite($dir.'/task.md', $content)`.
    - Do NOT call writeStatus from here — the orchestrator emits `new` and `selected` separately per D-03.

    Public method `writeStatus(string $repoSlug, string|int $taskId, string $state): void`:
    - Resolve $dir via `taskDir(...)`; ensure exists.
    - $statusPath = "{$dir}/status.md".
    - Compute now via `now()`. Render frontmatter pairs: state, updated_at — in that order.
    - Build the transitions body:
      - If the existing $statusPath does NOT exist on disk: emit the table header from scratch (`## Transitions\n\n| Timestamp (UTC)        | State     |\n|------------------------|-----------|\n`) and then one row for the current transition.
      - If the existing $statusPath EXISTS: parse out everything below the second `---` delimiter (the existing markdown body), and append one new row `| {now} | {state} |\n` to it. The transitions table header survives; prior rows survive verbatim.
    - Compose: `"---\n{$frontmatter}---\n\n{$body}"`.
    - Write atomically.
    - Update `$this->lastState["{$repoSlug}/{$taskId}"] = $state`.

    Public method `writeBlockedIfNotTerminal(string $repoSlug, string|int $taskId): void`:
    - $current = `$this->lastState["{$repoSlug}/{$taskId}"] ?? null`.
    - If $current is null OR === 'pr_open' OR === 'blocked', return immediately.
    - Otherwise call `$this->writeStatus($repoSlug, $taskId, 'blocked')`.

    Private helper `now(): string` — returns `(string) ($this->clock)()` if $this->clock is not null, else `gmdate('Y-m-d\TH:i:s\Z')`.

    Private helper `taskDir(string $repoSlug, string|int $taskId): string` — per D-05 and D-06: `$home = $this->homeOverride ?? HomeDirectory::resolve()`; `$repoDir = str_replace('/', '__', $repoSlug)`; return `"{$home}/.copland/tasks/{$repoDir}/" . (string) $taskId`. NOTE: the slug arrives in display form (`owner/repo` or `copland`); the slash collapse to `__` happens INSIDE the writer, not at the call site, so the orchestrator stays slug-agnostic.

    Private helper `ensureDirectoryExists(string $directory): void` — verbatim shape from RunLogStore.php lines 32-41: is_dir guard, mkdir with mode 0755 and recursive=true, double-check, throw RuntimeException("Failed to create task directory at {$directory}") on failure.

    Private helper `atomicWrite(string $path, string $content): void` (~10 lines per D-09):
    - $tmp = $path . '.tmp' — KEEP the tmp in the destination directory per RESEARCH Pitfall 2.
    - If `file_put_contents($tmp, $content)` returns false, throw `RuntimeException("Failed to write {$tmp}")`.
    - If `! rename($tmp, $path)`, throw `RuntimeException("Failed to rename {$tmp} to {$path}")`.

    Private helper `renderFrontmatter(array $pairs): string` — hand-rolled per Don't-Hand-Roll guidance:
    - Iterate key=>value pairs in insertion order.
    - For each value: `$escaped = str_replace(["\\", "\""], ["\\\\", "\\\""], (string) $v);`
    - Concatenate `"{$key}: \"{$escaped}\"\n"`.
    - Return the concatenation (no enclosing `---` — caller wraps).

    Style: 4-space indent, LF line endings (matches .editorconfig). No comments except a single-line note above `atomicWrite` explaining the rename-atomicity invariant (per CLAUDE.md "Document non-obvious algorithm choices"). Type-hint everything; explicit `void` returns.

    Do NOT add per-source branching (GH vs Asana) — the writer is source-agnostic per RESEARCH Anti-Patterns. Do NOT add `progressCallback` / `pushLog` calls — the writer is silent per D-12 / CONTEXT Specifics. Do NOT call writeStatus from writeNewTask — the orchestrator emits states.

    Do NOT create `runs/<run-id>/` subdirectories (D-14, Phase 21 owns this). Do NOT poll for PR-merge state (D-17, deferred to v2.1). Do NOT modify `~/.copland/logs/runs.jsonl` (D-16, additive-only). Do NOT modify AsanaService for source_url synthesis (per RESEARCH A1 / Open Q1 — Phase 20 writes `source_url: ""` for Asana sources). Do NOT use `Symfony\Component\Yaml\Yaml::dump()` for frontmatter (per Don't-Hand-Roll — TaskLoader's parser is intentionally narrow).
