<objective>
Ship the read side of the v2.1 hybrid config architecture: a single `copland config:show {--json}` subcommand that emits a stable, JSON-serializable snapshot of the merged global + per-repo configuration. This is the contract every Godot config screen consumes (Phases 24–26 build write subcommands on top of this shape).

Purpose: Downstream consumers (Godot console, future tooling) must read the merged config without re-implementing YAML schema knowledge. PHP owns the schema; consumers read JSON.

Output:
- `tests/fixtures/config/show-snapshot.json` — canonical v1 schema example (the contract).
- `app/Services/ConfigShowService.php` — pure-PHP snapshot builder, fully unit-tested.
- `app/Commands/ConfigShowCommand.php` — Laravel Zero command implementing the JSON-only stdout discipline and exit-code rules.
- Pest unit + feature coverage hitting every case in CONTEXT.md's "Test coverage targets" list, including the redaction guarantee.
</objective>
