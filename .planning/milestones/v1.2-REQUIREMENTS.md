# Requirements — v1.2 Onboarding (archived)

**Milestone:** v1.2 Onboarding
**Shipped:** 2026-05-26 (partial — Init Wizard dropped)
**Goal as originally scoped:** A guided init experience that takes a new user from zero to a configured, running Copland setup without reading the docs.

> **Note (2026-05-26):** Milestone closed with Phase 18 only. The Init Wizard (Phase 19 / INIT-01..07) was dropped because the v2.0 direction (Godot Console + task-directory persistence) changes what onboarding looks like; an init wizard built for the old shape would be thrown away. INIT-01..07 are listed under "Deferred / Superseded" below for traceability.

---

## Shipped Requirements

### Automate Command

- [x] **AUTO-01**: User can run `copland automate` to install the macOS LaunchAgent (Phase 18)
- [x] **AUTO-02**: Running `copland setup` shows a deprecation notice and delegates to `copland automate` (Phase 18)

---

## Deferred / Superseded

These requirements were defined for v1.2 but never planned or executed. They are not promoted to v2.0 — onboarding will be redesigned around the console.

- **INIT-01..07** — Interactive `copland init` wizard. Superseded by v2.0 direction; revisit as part of a future onboarding milestone once the console shape is settled.

---

## Out of Scope (unchanged)

- GUI or web-based setup wizard — CLI only
- Auto-detection of repos from git remotes — explicit registration only
- Windows support — macOS/Linux only
