<objective>
Extend the Copland planner so it reads each file in `files_to_change` (via a new bounded agentic loop with a `read_file` tool) and emits an exact `changes: [{file, old, new, reason}]` array. Executor applies those diffs verbatim via `replace_in_file`, eliminating the "old text not found" failures small Ollama models hit when forced to invent precise text.

Purpose: A Claude-class planner can ground diffs in real file content; weaker executors (Ollama) only have to copy `old`/`new` strings into a tool call instead of synthesizing them.

Output: Updated PlanResult schema, planner with agentic loop + read_file, executor + prompts that consume the new field, validator that enforces the contract, plus tests covering happy-path emission and validator rejection.
</objective>
