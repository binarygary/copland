<objective>
Add a `claude-code` provider to Copland that shells out to `claude -p` (Claude Code CLI headless) for the selector / planner / executor stages. The user can then drive Copland with a Claude Code monthly plan instead of paying for Anthropic API tokens.

Purpose: Decouple Copland from per-token Anthropic billing. Each stage makes ONE opaque `claude -p` call; Claude Code drives its own internal agent loop with its own native tools. From Copland's perspective: prompt + allowed-tools whitelist in, structured JSON out, plus a `total_cost_usd` value we can surface.

Output: New `ClaudeCodeRunner` (Process wrapper) + new `ClaudeCodeClient implements LlmClient` (single-shot adapter) + factory wiring + per-stage cost routing + startup warning + unit tests. Anthropic / Ollama / OpenRouter paths untouched.
</objective>
